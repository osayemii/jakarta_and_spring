**Bio:** Aptech Java/Spring coursework repository with Jakarta EE and Spring project folders.

**Description:** Java/Spring coursework organized by project folder.

## Running the code

There is no single entry point for the whole repo; run individual projects from their folders. Check each folder for its own README, `package.json`, `pubspec.yaml`, `pom.xml`, or build files.
